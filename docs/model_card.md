# graphForge Model Card

> 作者：晨星 · 版本 0.1.0 · 2026-10-11

## 模型细节

| 项 | 内容 |
|----|------|
| 任务 | 图节点社区发现（无监督）、谱聚类、图同构判别、节点中心性 |
| 核心方法 | Louvain 模块度优化 + 谱聚类 + Weisfeiler-Lehman 图核 + PageRank |
| 标志性算法 | `CommunityFuse`（修复模块度分辨率极限） |
| 实现 | 纯 NumPy 手写，零 scipy/networkx/sklearn 依赖 |
| 输入 | 无向图（邻接矩阵或边列表） |
| 输出 | 社区划分 / 谱嵌入 / 图核值 / PageRank 向量 |
| 确定性 | 是（同 seed 逐位可复现） |

## 评估

基准套件：3 个 regime × 5 seeds = 15 runs，planted-partition SBM。

| 方法 | ARI mean | 备注 |
|------|---------:|------|
| CommunityFuse | **0.9910** | 给 k=4 |
| 谱聚类（已知 k） | 0.9899 | SBM 统计天花板（参考） |
| 普通 Louvain | 0.7571 | 领域标准基线（不给 k） |
| 邻接行 k-means | 0.5472 | 给 k |
| 随机划分 | ≈ 0.00 | 对照 |

**门禁（DoD）：**

- G1 恢复力：旗舰 ARI ≥ 0.90 → **0.9910** ✅
- G2 胜点：旗舰 − 普通 Louvain ≥ 0.05 → **+0.234** ✅
- G3 模块度单调：跨层下降 ≤ 1e-9 → **0.0** ✅
- G4 不变量：PSD / 谱嵌入正交（误差 2.22e-16）/ WL 同构 → ✅

消融（unbalanced regime）：含归并+精炼组件 vs 普通 Louvain → **Δ = +0.357**。

## 局限性（诚实声明）

1. **已知 k 的天花板**：在 planted-partition SBM 上，给定真实社区数 k 的谱聚类 ARI（0.9899）≈ 旗舰（0.9910）。graphForge **不声称超越**该天花板；其核心贡献是**在 Louvain 不给 k 导致严重过度切分（ARI 0.7571）时修复分辨率极限**。
2. **分辨率极限的残余**：在不平衡 + 强噪声图上，贪心归并可能误并相邻社区；此时粗化谱归并策略会被自动选优，但仍可能略低于理想划分。
3. **谱方法依赖连通性**：谱聚类对连通分量敏感；当前实现假设单一连通分量（基准内成立）。
4. **规模**：纯 NumPy 实现，适用于中小图（n ≲ 10⁴）；超大图建议接入稀疏矩阵。

## 伦理与用途

社区发现用于理解网络结构与群体划分，不针对个体隐私。图核 / PageRank 可迁移至分子、社交、引用网络等。
